3. Mostrar en portal

REVIEWPendiente de validar. No visible.
NOInformación desactivada. No visible.
Ante cualquier duda: usar REVIEW primero y validar después.

4. Cómo manejar cambios

Si cambia un email, teléfono o portal

Si el procedimiento sigue siendo el mismo, edita la fila existente. No crees otra fila solo porque cambió un contacto.

Si existe otro procedimiento válido

La misma compañía puede tener dos filas si realmente existen dos métodos distintos, por ejemplo llamada y email.

Si aparece un carrier nuevo

  1. Crear una fila nueva.
  2. Colocar Estado = En revisión.
  3. Colocar Mostrar en portal = REVIEW.
  4. Completar todos los datos disponibles.
  5. Después de verificarlo, cambiar a Estado = Comprobado y Mostrar en portal = SI.

5. Reglas de captura

Firma requerida / Cliente debe solicitar / Cliente en línea: usar solamente los dropdowns Si, No, Por confirmar, No indicado.

Tiempo estimado: usar tiempos claros como 1 Día, 24 Horas, 2-3 días, 3-5 días o Inmediato. No inventar tiempos no confirmados.

Procedimiento / Observaciones: debe explicar el proceso completo para que otra persona pueda ejecutarlo sin preguntar.

Actualización registrada: no tocar manualmente; fecha y hora se actualizan automáticamente.

Verificado por: registrar quién confirmó la actualización.

6. Validación después de un cambio

  1. Abrir Loss Run Center.
  2. Confirmar que arriba aparezca LIVE.
  3. Confirmar que la fuente sea Apps Script API.
  4. Buscar la compañía modificada.
  5. Verificar método, email, teléfono, portal, firma, tiempo e instrucciones.
  6. Si Mostrar en portal = REVIEW o NO, confirmar que esa fila no aparezca.

7. Qué NO debe hacer el asistente

No utilizar instrucciones que impliquen hacerse pasar por el cliente, crear emails falsos, dar información falsa o actuar sin autorización cuando el carrier la exige. Si aparece una instrucción antigua de este tipo, cambiar el registro a REVIEW y reportarlo.
  • No borrar filas antiguas.
  • No editar GitHub.
  • No editar Apps Script.
  • No editar loss-run-center.html.
  • No cambiar nombres de columnas.
  • No mover columnas.
  • No escribir manualmente la fecha de actualización.
  • No publicar información no verificada.

Regla final

La única base que alimenta Loss Run Center es Directorio Maestro.
